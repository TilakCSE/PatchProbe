## Before presenting

Follow [the demo runbook](../docs/DEMO_RUNBOOK.md) to train the local artifact, start Streamlit, and prepare the VS Code walkthrough. Open the repository root in VS Code. Slides 7–9 name the files to show. Keep [the model card](../docs/MODEL_CARD.md) and [presentation Q&A](../docs/PRESENTATION_QA.md) available for questions.

The deck describes the 50 pilot decisions as human-confirmed. It does not assign historical annotation counts to individual teammates. Slide 12 assigns a future independent re-review of 12–13 rows per teammate. The pilot metrics and limitations are intentionally visible; present them as diagnostic evidence, not deployment readiness.
